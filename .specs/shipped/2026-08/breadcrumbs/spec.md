# Breadcrumbs

We replace the second header bar (currently the title) with two columns.
* The left column contains the breadcrumbs
* The right column contains nothing for now (for future action buttons in different spec)


## breadcrumbs bar 
See [Breadcrumbs](https://www.w3.org/TR/wai-aria-practices-1.1/#breadcrumb)

* The breadcrumbs bar should be accessible
* It should be a landmark
* The structure should have the same parents as the menu bar, with the dahsboard of the project as the first item.

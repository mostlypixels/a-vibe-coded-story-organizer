# Birth and death / Creation and destruction

We should be able to track down the age of some of the codex entities, especially characters.

We must link the "creation/birth" and "destruction/death" of codex entities to events.

For the character "Jane Doe", with a "birth" event in 1980, a scene set in 2000 should be able to calculate that she is now 20 years old (with more precision based on the exact date).

The nomenclature of the events should depend on the entity type: characters are alive, thus born.
However, organizations and locations are "created" and "destroyed" (or "dissolved" or "abolished").

On the codex entity's edit page, we must be able to create those events "on the fly" with a date picker.

The age of the characters is visible on the scenes "edit" page.

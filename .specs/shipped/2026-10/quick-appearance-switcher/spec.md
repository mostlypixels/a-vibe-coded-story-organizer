# Quick appearance switcher

A new menu entry placed to the left of the user menu, as a "palette" icon.

In a dropdown, display:

* the existing themes in a small square thumbnail of the theme's colors.
  * the name is displayed in a tooltip.
* For both the interface and manuscript fonts:
  * a simplified version of the font picker (dropdown)
  * a +/- button to increase/decrease the font size.

Changes are immediately applied and persisted.

The dropdown should be loaded in ajax not to clutter the html.

# Open questions

1. **Land in the Write page or the edit page after create?** Recommend Write: it is the daily
   writing loop, and the body has focus there.
2. **Drop Description from the create form too, or only Contents?** Recommend both: a
   description is prose too, and the edit page autosaves it.
3. **Warn before leaving the create form with a title typed?** Recommend no: a title and a few
   selects are cheap to type again. Add it only if a second create form needs it.
4. **Add a quick "New scene" in the Write page itself (chapter + title in a dialog)?** Recommend
   not now: a separate change, after this one ships.
5. **Remove an empty scene that the writer leaves right after create?** Recommend no: it is a
   normal scene, and they can delete it. No cleanup job.
